# Защёлка подлокотника центральной консоли Mitsubishi Pajero (верхняя)

3D-модель **верхней защёлки** крышки подлокотника центральной консоли
Mitsubishi Pajero / Montero. Версия **v3** — перемоделирована с нуля по
исходным фотографиям и привязана к реальным размерам оригинала.

| | |
|---|---|
| OEM-номер | **MR532555** (верхняя); парная нижняя — MR532556 |
| Применимость | Pajero / Montero **NM … NX** (≈ 2000–2021), V73/V75/V77/V93/V97 |
| Реальный габарит OEM | **≈ 47 × 34 × 29 мм**, отверстия ≈ 35 мм ц-ц, масса ≈ 15 г |
| Габарит модели | **47 × 27 × 33 мм**, ≈ 16 г (PETG) — совпадает с оригиналом |
| Материал печати | PETG / coPET |

## Что это за деталь и откуда размеры

Заводского чертежа Mitsubishi в открытом доступе нет. Габариты взяты из
карточек продавцов запчастей, масса **15 г** — из genuine-каталога Amayama.
Модель прошла автоматический **self-check** (см. ниже): watertight,
согласованные нормали, габариты и масса в целевом диапазоне OEM.

### Готовые 3D-модели в интернете (для сверки/альтернативы)

- **Printables 818297 / MakerWorld 433014** — Jeandré Gouws (одна модель на
  двух площадках), снята с реальной детали — лучший «эталон»;
- Printables 485480 — plabs.cz, но это **Pajero Sport** (другая деталь).

Скачать их из этой среды нельзя (площадки отдают 403), но с телефона/браузера
открываются свободно.

## Асимметрия монтажного фланца

У оригинала крепёжные «уши» могут отличаться (одно длиннее). Генерируются
**два зеркальных варианта** — печатайте тот, что совпал с посадочным местом:

| Файл | Длинное ухо |
|------|-------------|
| `pajero_upper_latch_A.3mf` / `.stl` | слева |
| `pajero_upper_latch_B_mirror.3mf` / `.stl` | справа |

`pajero_upper_latch.3mf` — копия варианта A. По умолчанию уши симметричны
(`EAR_LONG == EAR_SHORT`); задайте разные значения в `generate_latch.py`,
если нужно.

## Self-check (цикл самопроверки)

`generate_latch.py` при каждом запуске печатает отчёт и проверяет:
watertight, согласованность нормалей, ширину 42–52 мм, глубину 24–34 мм,
высоту 28–38 мм, массу 8–24 г. Плюс рендер `preview.png` в трёх ракурсах
исходных фото для визуальной сверки геометрии (фланец + 2 зенкованных
отверстия + центральный прилив с отверстием + куполообразный корпус + крючок).

## Печать на Bambu Lab A1, филамент PETG / coPET

Ориентация: **фланцем на стол**, купол вверх → поддержки не нужны, слои
поперёк нагрузки на крючок.

### Профиль под ваш филамент (MonoFilament coPET, 1.75 мм, хаки)

За основу — **Generic PETG**, правки:

| Параметр | Значение |
|----------|----------|
| Сопло | **255 °C** (1-й слой 260) |
| Стол | 75 °C, Textured PEI |
| Слой | 0.16 мм |
| Стенки / верх-низ | 4 / 5 |
| Заполнение | 40–50 % Gyroid |
| Обдув | 30 % (0 % на 1-м слое) |
| Flow ratio | ≈ 0.95 |
| Сушка | 65 °C, 6–8 ч перед печатью |

### Как отправить в печать (Bambu Handy)

1. Импорт → выбрать `pajero_upper_latch_A.3mf` (или B).
2. Принтер **A1**, филамент — профиль выше.
3. Slice → Print.

> Нарезку (G-code) выполняет само приложение/облако Bambu на вашей стороне —
> отдать готовый G-code отсюда нельзя (нужен запущенный Bambu Studio с вашим
> профилем принтера). 3MF — правильный «готовый к нарезке» формат.
