## ⚠️ Важно про размеры

Заводские размеры этой детали Mitsubishi нигде не публикует. Модель
построена **по пропорциям с фотографий** и стандартным размерам
саморезов салонного крепежа. Поэтому модель **параметрическая** — все
критичные для посадки значения вынесены в начало файлов.

**Перед финальной печатью** замерьте штангенциркулем на оригинале хотя бы:

- `HOLE_SPACING` — расстояние между центрами крепёжных отверстий;
- `HOLE_DIA` / `CSK_DIA` — диаметр отверстия и зенковки под саморез;
- профиль крючка (`HOOK_*`) — он определяет зацеп за ответную часть.

Поправьте константы и перегенерируйте STL.

## Печать на Bambu Lab A1, филамент PETG / coPET

Деталь силовая (крючок работает на зацеп и износ), поэтому печатаем
плотно и ориентируем на прочность.

### Ключевые настройки (Bambu Studio, профиль *Generic PETG*)

| Параметр | Значение |
|----------|----------|
| Сопло / слой | 0.4 мм / **0.16 мм** (тонкий слой = крепче зацеп) |
| Температура сопла | **250–260 °C** (coPET ближе к верхней границе) |
| Стол | **70–80 °C**, Textured PEI |
| Стенки (walls) | **4 периметра** |
| Верх / низ | по 5 слоёв |
| Заполнение | **40–50 %**, узор Gyroid |
| Скорость | 60–80 мм/с (внешние стенки до 40) |
| Обдув | **30–50 %** (PETG не любит сильный обдув — иначе хрупко) |
| Поддержки | как правило **не нужны** (см. ориентацию) |
| Адгезия | Brim 5 мм, если плита маленькой опоры |

### Ориентация на столе

- Кладём деталь **базовой пластиной (фланцем) на стол** — отверстия
  смотрят вверх. Так слои ложатся поперёк нагрузки на крючок, а
  нависаний почти нет → поддержки не требуются.
- Зенковки под саморезы окажутся сверху и пропечатаются чисто.

### Советы для PETG/coPET на A1

- Просушите филамент (PETG активно тянет влагу): 65 °C, 6–8 ч.
- Чуть уменьшите flow (≈ 95 %), если на поверхности «сопли»/нити.
- Первый слой — помедленнее (20–25 мм/с) для адгезии.
- coPET немного гибче и прочнее обычного PETG — отлично подходит для
  защёлок и клипс.
