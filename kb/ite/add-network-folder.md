# Добавление сетевой папки для работы с IT Enterprise

> KB: `ite` · Тема: первичная настройка рабочего места

## Контекст

При первичной настройке рабочего места для работы с десктопным приложением **IT Enterprise** тимлид присылает UNC-путь к сетевой папке, например:

```
\\Kyiv-kovba-iv-n\it_dev
```

Эту папку нужно «добавить» на рабочей машине — то есть подключить её как сетевой диск, чтобы приложение могло обращаться к файлам по короткому пути (`Z:\...`), а Windows автоматически восстанавливал соединение после перезагрузки.

## Что делать (Windows 10/11)

### Вариант 1 — через Проводник (GUI)

1. Откройте **Проводник** (`Win + E`).
2. В левой панели нажмите правой кнопкой на **«Этот компьютер»** → **«Подключить сетевой диск…»**
   (англ.: *This PC* → *Map network drive…*).
3. В поле **«Диск»** выберите свободную букву (обычно `Z:` для IT Enterprise).
4. В поле **«Папка»** вставьте путь, который прислал тимлид:
   ```
   \\Kyiv-kovba-iv-n\it_dev
   ```
5. Отметьте галочки:
   - ☑ **Восстанавливать подключение при входе в систему**
   - ☑ **Использовать другие учётные данные** — если ваш доменный логин/пароль отличается от того, под которым вы залогинены в Windows.
6. Нажмите **«Готово»**. При запросе учётных данных введите доменный логин в формате `KOVBA\ivan.ivanov` и пароль.

### Вариант 2 — через командную строку

```cmd
net use Z: \\Kyiv-kovba-iv-n\it_dev /persistent:yes
```

Если нужны другие учётные данные:

```cmd
net use Z: \\Kyiv-kovba-iv-n\it_dev /user:KOVBA\ivan.ivanov * /persistent:yes
```

(`*` — пароль будет запрошен интерактивно, чтобы не светить его в истории команд.)

### Проверка

```cmd
net use
dir Z:\
```

В списке должна быть строка с `Z:` и статусом `OK`. Если в `Z:\` видны рабочие файлы IT Enterprise — всё подключено корректно.

## Частые проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| `Системная ошибка 53. Не найден сетевой путь.` | Нет сетевой связности с хостом `Kyiv-kovba-iv-n` (VPN не поднят / не в офисной сети). | Подключитесь к корпоративному VPN, затем повторите. Проверьте `ping Kyiv-kovba-iv-n`. |
| `Системная ошибка 1326. Неверное имя пользователя или пароль.` | Учётка не та / истёк пароль. | Используйте `/user:DOMAIN\login` с актуальными доменными кредами. |
| `Системная ошибка 1219. Конфликт учётных данных.` | На эту шару уже есть открытая сессия под другим пользователем. | `net use \\Kyiv-kovba-iv-n\it_dev /delete`, затем повторите подключение. |
| Диск пропадает после перезагрузки. | Не стоял флаг **«Восстанавливать при входе»** / не указан `/persistent:yes`. | Переподключите с правильным флагом. |
| IT Enterprise не видит файлы, хотя `Z:\` открывается. | Приложение запущено **от имени администратора**, а диск примонтирован под обычным пользователем (в Windows это разные сессии). | Запускайте IT Enterprise без «Запуск от имени администратора», либо мапьте диск и в админ-сессии тоже. |

## Что сообщить тимлиду, если не получилось

- Скриншот ошибки (или текст из `net use`).
- Подняли ли VPN, пингуется ли `Kyiv-kovba-iv-n`.
- Под каким доменным логином пробовали подключаться.
